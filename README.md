# ঘিআলয় landing page

এই project-টি build ছাড়াই GitHub Pages-এ deploy করা যাবে।

## GitHub Pages deploy

1. এই folder-এর সব file একটি GitHub repository-তে push করুন।
2. GitHub repository-তে **Settings → Pages** খুলুন।
3. **Deploy from a branch** নির্বাচন করে `main` branch এবং `/ (root)` folder সিলেক্ট করুন।
4. Save করুন। কিছুক্ষণ পর GitHub Pages URL-এ landing page দেখা যাবে।
